# 🌿 MindWell

> **Your digital space for a better mind. 💚**

MindWell is a full-stack **MERN mental wellness platform** built to help users track their mood, relax, and get supportive AI-powered conversations.

### ✨ Features

* 🧠 AI-powered wellness chat
* 😊 Mood tracking & analytics
* 🧘 Meditation & breathing exercises
* 🎵 Relaxing music & soundscapes
* 🎮 Mini wellness games
* 👤 Profile & privacy management
* 🔐 JWT authentication & secure user data

### 🛠️ Tech Stack

**Frontend:** React.js • Tailwind CSS • Axios • Chart.js
**Backend:** Node.js • Express.js • MongoDB • JWT
**AI:** OpenAI GPT / Google Gemini

### 🚀 Run Locally

```bash
# Backend
cd server
npm install
npm run dev

# Frontend
cd client
npm install
npm start
```

Create a `.env` file in `server/` with your MongoDB, JWT, and AI API credentials.
